新建文件夹后，用VScode打开
注意要信任文件夹
之后Ctrl+Shift+P 输入 git init
会看到 Git: 初始化仓库 这个选项，选它
左下角出现 master 或 main 分支名
左侧源代码管理图标（三个圈）亮起

浏览器打开 https://github.com/new：
仓库名：gitproject
选 Public
三个勾都不要打（README、.gitignore、license）
点 Create repository

VS Code 终端里执行：
git remote add origin https://github.com/Jeak73/gitproject.git
git remote -v

Ctrl+s 保存
按+暂存更改
在“消息里添加备注”提交

提交后点击左下角的圈，上面的推送也可以

创建分支
点击左下角的main弹出创建新分支，输入新分支的名字回车
编辑文件，保存
在源代码管理面板写提交说明，提交

合并分支
先切换到主分支
执行合并Ctrl+Shift+P 输入git merge,选择Git合并分支，选择要合并的分支
推送

删除分支
光标在放置在图标上右键删除分支
再推送
